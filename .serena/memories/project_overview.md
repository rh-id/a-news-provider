# Project Overview: a-news-provider

RSS aggregator Android app ("A simple and easy to use RSS aggregator that delivers news to your smartphone").
GitHub: https://github.com/rh-id/a-news-provider (repo root package `m.co.rh.id.a_news_provider`).

**Purpose:** production-quality demo app for the author's libraries:
- [a-navigator](https://github.com/rh-id/a-navigator) — StatefulView-based UI navigation (no Fragments)
- [a-provider](https://github.com/rh-id/a-provider) — Service Locator DI (Provider + ProviderModule)

## Tech Stack
- **Language:** Pure Java 17 (NO Kotlin anywhere). Core library desugaring enabled (`desugar_jdk_libs:2.1.5`).
- **Build:** Gradle 9.8.0 wrapper, Android Gradle Plugin 9.4.1, Groovy DSL, Gradle version catalog (`gradle/libs.versions.toml`, build files use `libs.*` aliases). JitPack repo for `com.github.rh-id:*` artifacts (a-provider v0.0.27, a-navigator v0.0.73).
- **Android:** compileSdk 37, targetSdk 37, minSdk 21. versionCode 77, versionName 2.2.0 (v2.2.0 tagged 2026-10-11).
- **Async:** RxJava 3 (rxjava 3.1.12 PINNED — final 3.x release; RxJava 4 is alpha-only, not on Maven Central; 3.x requires API 21+) + rxandroid 3.0.2.
- **Persistence:** Room 2.7.2 (wired via `annotationProcessor`, NOT kapt/ksp), DB `a-news-provider.db` version 11 with migrations 1→11.
- **Networking:** Volley 1.2.1 (RequestQueue + 20 MiB disk cache, ImageLoader with 20-entry LruCache).
- **Background:** WorkManager 2.10.5 (default initializer removed; manual init in `MainApplication`).
- **Other:** material 1.13.0, recyclerview 1.4.0, LeakCanary plumber-android 2.14, `com.github.rh-id:AndroidShowCase:v0.0.1`. Licenses page is generated by the project's own `gradle/license-html-generator.gradle` script (task `generateLicenseHtml`, applied in :app, auto-runs before `preBuild`) reading overrides from `app/licenses.yml` (replaced cookpad license-tools in 2026).

## Gradle Modules (settings.gradle)
- `:app` — applicationId `m.co.rh.id.a_news_provider`; UI (StatefulViews), Commands, non-UI RssService, WorkManager workers, notifications, DI root.
- `:base` — library; Room DB (entities/DAOs/migrations), AppSharedPreferences, base provider modules, logger wiring, network-status helper, UrlNormalizer.
- `:component-network` — library; Volley `RssRequest` + RSS 2.0/Atom/RDF (RSS 1.0) feed parsers (supports `media:content`, `media:thumbnail`, `enclosure`).

## Key Features (user-facing)
RSS 2.0/Atom/RDF support, OPML import/export (with toast count of feeds not added), media images/videos (video download via system DownloadManager to `Downloads/<feedName>/`), favorites + All/Unread/Read/Favorites filters, newest/oldest sort, mark-all-read, search by title/description/category with tappable category chips, next/previous article navigation in detail (toolbar + edge swipe, default on, togglable), periodic background sync (1-24h, default 6h), auto mark-read retention window (7/14/30/90d, opt-in), mark-read-on-scroll (opt-in), open-links mode (default browser / Custom Tabs, opt-in, falls back to default browser), pause/mute channels, duplicate-feed warning (UrlNormalizer + RedirectDuplicateChecker), Material You dynamic color (Android 12+, default on), per-channel grouped sync notifications (POST_NOTIFICATIONS requested at runtime on 13+), 11 languages (incl. Simplified Chinese since v1.15.0), themes (system/light/dark), one-hand mode, in-app log viewer, licenses screen, themed icon. Supports Android 5.0+.

## Supported Feed Parsing
Root tag dispatch: `rss` → RSS 2.0, `feed` → Atom, `rdf:RDF` → RDF/RSS 1.0. Dates parsed best-effort from RFC-822 and ISO-8601 formats (`RssDateParser`).
